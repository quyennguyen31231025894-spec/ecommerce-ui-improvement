## Nội dung từng Lab

- **Lab 08 – JavaScript 1: Language Foundations:** nhúng JavaScript vào trang HTML, dùng Console, các đối tượng String/Date/Math, mảng, hàm, hàm như đối tượng, tạo đối tượng và mảng các đối tượng.
- **Lab 09 – JavaScript 2: DOM and Events:** chọn và thay đổi phần tử HTML, quan hệ trong cây DOM, tạo và xóa phần tử, xử lý sự kiện, gỡ lỗi bằng Debugger, làm việc với form và kiểm tra dữ liệu.
- **Lab 10 – JavaScript 3: jQuery:** cài đặt jQuery, bộ chọn cơ bản và nâng cao, xử lý sự kiện, chèn phần tử DOM, hiệu ứng fade/slide/animate, GET Requests và xử lý kết quả bằng jqXHR.

## Hướng dẫn truy cập

1. Mở đường dẫn trang chủ GitHub Pages ở trên.
2. Ở mục **Bài Lab**, bấm **Xem Lab 08 / Lab 09 / Lab 10**.
3. Trang của mỗi Lab liệt kê các Exercise, bấm **Mở bài** để xem kết quả chạy.
4. Với các bài cần xem Console hoặc Debugger (8.5, 8.8, 9.2, 9.5, 9.6), mở DevTools của trình duyệt (Cmd + Option + J trên Mac, F12 trên Windows).
